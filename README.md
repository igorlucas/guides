# Guias de tecnologia

Repositório de guias práticos para pessoas que trabalham com tecnologia.

## Organização

Os guias ficam em `guias/`, agrupados por tecnologia. Use um arquivo Markdown
por assunto:

```text
guias/
└── <tecnologia>/
    └── <assunto>.md
```

Por exemplo, guias sobre Git ficam em `guias/git/`. Cada guia deve ter um título
claro e, quando fizer sentido, seções para pré-requisitos, passos, validação,
solução de problemas e referências.
