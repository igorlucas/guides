# Guia de GitHub Achievements

Este documento reúne os principais Achievements (conquistas) disponíveis no GitHub, o que é necessário para obtê-los e sugestões práticas para alcançá-los. Algumas conquistas históricas foram aposentadas e não podem mais ser obtidas. 【1-b4bd3d】【2-db1378】【3-54874a】

Os selos abaixo são carregados diretamente dos servidores de imagens do GitHub; não há cópias das imagens armazenadas neste repositório. A lista de referência foi consultada no catálogo comunitário [Omni-HuB/all-github-badges](https://github.com/Omni-HuB/all-github-badges), que declara licença CC0 1.0. Essa licença do catálogo não implica uma licença para as imagens oficiais do GitHub.

---

# Como Ver Seus Achievements

Acesse:

```text
GitHub
→ Profile
→ Achievements
```

Ou diretamente pelo seu perfil.

# Achievement: Pull Shark <img src="https://github.githubassets.com/images/modules/profile/achievements/pull-shark-default.png" alt="Selo Pull Shark" width="32">

## Descrição

Concedido para usuários que possuem Pull Requests mergeados. Possui múltiplos níveis. 【1-b4bd3d】【2-db1378】

## Como Obter

Criar Pull Requests que sejam aceitos e mergeados.

### Exemplo

```text
Criar Branch
↓
Realizar Commit
↓
Abrir Pull Request
↓
Merge
```

---

## Níveis

| Nível | Requisito |
|---------|---------|
| Base | 2 PRs mergeados |
| Bronze | 16 PRs mergeados |
| Silver | 128 PRs mergeados |
| Gold | 1024 PRs mergeados |

【2-db1378】【4-dda1e8】

---

## Plano de Ação

Criar um repositório pessoal:

```text
github-achievement-lab
```

Fazer pequenas alterações:

```text
README
Documentação
Exemplos
Scripts
```

Abrir PRs regularmente.

# Achievement: Pair Extraordinaire <img src="https://github.githubassets.com/images/modules/profile/achievements/pair-extraordinaire-default.png" alt="Selo Pair Extraordinaire" width="32">

## Descrição

Concedido para Pull Requests mergeados contendo commits coauturados. Possui múltiplos níveis. 【1-b4bd3d】【2-db1378】

---

## Como Obter

Criar commits utilizando:

```text
Co-authored-by:
```

Exemplo:

```text
Co-authored-by: João Silva <joao@empresa.com>
```

Após o merge do PR o progresso será contabilizado.

---

## Níveis

| Nível | Requisito |
|---------|---------|
| Base | 1 PR coauturado |
| Bronze | 10 PRs coauturados |
| Silver | 24 PRs coauturados |
| Gold | 48 PRs coauturados |

【2-db1378】【4-dda1e8】

---

## Plano de Ação

- Trabalhar com um colega.
- Realizar pair programming.
- Adicionar coautoria aos commits.
- Criar PRs pequenos e frequentes.

# Achievement: Quickdraw <img src="https://github.githubassets.com/images/modules/profile/achievements/quickdraw-default.png" alt="Selo Quickdraw" width="32">

## Descrição

Concedido quando uma Issue ou Pull Request é fechada em menos de 5 minutos após sua criação. 【1-b4bd3d】【3-54874a】

---

## Como Obter

Criar uma Issue:

```text
Teste Quickdraw
```

Fechar imediatamente.

Ou:

Criar um Pull Request e fechá-lo rapidamente.

---

## Plano de Ação

```text
Criar Issue
↓
Fechar em menos de 5 minutos
```

Resultado esperado:

```text
Quickdraw
```

---

# Achievement: Starstruck <img src="https://github.githubassets.com/images/modules/profile/achievements/starstruck-default.png" alt="Selo Starstruck" width="32">

## Descrição

Concedido quando um repositório criado por você alcança determinada quantidade de estrelas. Possui múltiplos níveis. 【1-b4bd3d】【2-db1378】

---

## Níveis

| Nível | Requisito |
|---------|---------|
| Base | 16 estrelas |
| Bronze | 128 estrelas |
| Silver | 512 estrelas |
| Gold | 4096 estrelas |

【1-b4bd3d】【4-dda1e8】

---

## Como Obter

Criar projetos úteis e públicos.

Exemplos:

```text
Documentação
Tutoriais
Ferramentas CLI
Scripts DevOps
Templates Terraform
Templates GitHub Actions
```

---

## Plano de Ação

Meta inicial:

```text
16 estrelas
```

Ações:

- README de qualidade
- Boa documentação
- Licença
- Exemplos de uso
- Divulgação em LinkedIn
- Divulgação em comunidades técnicas

# Achievement: YOLO <img src="https://github.githubassets.com/images/modules/profile/achievements/yolo-default.png" alt="Selo YOLO" width="32">

## Descrição

Concedido quando você realiza merge de um Pull Request sem revisão de código. 【3-54874a】【4-dda1e8】

---

## Como Obter

Fluxo:

```text
Criar Branch
↓
Commit
↓
Abrir PR
↓
Merge sem Review
```

---

## Plano de Ação

Criar um repositório de testes:

```text
github-achievement-playground
```

Abrir um PR simples.

Realizar merge diretamente.

# Achievement: Galaxy Brain <img src="https://github.githubassets.com/images/modules/profile/achievements/galaxy-brain-default.png" alt="Selo Galaxy Brain" width="32">

## Descrição

Relacionado a respostas aceitas em GitHub Discussions. Possui múltiplos níveis. 【1-b4bd3d】【4-dda1e8】

---

## Níveis

| Nível | Requisito |
|---------|---------|
| Base | 2 respostas aceitas |
| Bronze | 8 respostas aceitas |
| Silver | 16 respostas aceitas |
| Gold | 32 respostas aceitas |

【2-db1378】【4-dda1e8】

---

## Como Obter

Responder perguntas em Discussions e ter respostas marcadas como solução.

---

## Observação

O GitHub realizou mudanças na forma de obtenção deste Achievement e seu status já variou ao longo do tempo. Consulte a documentação atual do GitHub caso esteja perseguindo esta badge especificamente. 【3-54874a】【4-dda1e8】
